# Tributo a Charles Darwin

Página tributo al naturalista que explicó la evolución de las especies por selección natural. Es el proyecto 6 de mi ruta de 100 proyectos de desarrollo web.

## Tecnologías
- HTML5 semántico
- CSS

## Lo que aprendí
- Colores en CSS: nombres, hexadecimal, `rgb()` y `hsl()`, con transparencia
- Herencia del color del texto y degradados con `linear-gradient`
- Contraste de colores para que el texto sea legible
- Tipografía: listas de fuentes con familia genérica, `font-size`, `font-weight` y `line-height`
- Por qué usar `rem` en lugar de píxeles para el tamaño de texto
- El modelo de caja: contenido, `padding`, `border` y `margin`
- Centrar contenido con `max-width` y `margin: 0 auto`
- `box-sizing: border-box` para todos los elementos
- La fusión de márgenes verticales
- Bordes redondeados y sombras con `border-radius` y `box-shadow`
- Depurar el modelo de caja con las herramientas de desarrollador

## Créditos
- Retrato de Charles Darwin: dominio público, vía Wikimedia Commons.
- Cita: Charles Darwin, *El origen de las especies* (1859). Traducción propia.

## Cómo verlo
Descarga el repositorio y abre `index.html` en tu navegador.
